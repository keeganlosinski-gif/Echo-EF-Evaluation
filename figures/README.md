# Figures

This folder is intentionally empty.

Every figure the project produced (adjudication panels, the wrong-chamber evidence panel, the split-screen and rotated-export panels, the confident-failure panels, the orientation panel, the outlier screens) renders frames from EchoNet-Dynamic or CAMUS with overlays. Those frames are dataset content distributed under research-use terms, and this repository does not redistribute any of it, so none of the thirteen PNGs on disk were copied here.

If a figure is added later it will be regenerated from numbers only (for example the EF-band bias table or the internal-versus-external table as a chart), with no image content.

Holders of the datasets can regenerate the panels with the scripts in `../scripts/` (`_adjudicate.py`, `_chamber_screen.py`, `_acqtypes.py`) against their own copies.
